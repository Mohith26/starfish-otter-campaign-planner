Assumptions

How the planner works

  1. Every plane in the shell precesses together, so the planner works in the shell's own nodal frame where each plane is a fixed angle.
  2. Towing a client from the shell to the release altitude already drags Otter west in that frame. Instead of climbing straight back, Otter dwells low until the next client's plane comes around, then climbs; the climb's own drift is solved so it lands on the plane exactly.
  3. Clients are served in "soonest release" order (the RAAN walk). Each spiral uses Edelbaum low-thrust Δv with constant thrust and falling mass.
  4. Failures are random (Weibull lifetimes per satellite), so capacity is reported as a distribution over simulated histories, not one plan.
